- City, State, PIN code
- Optional landmark

COUPON:
RIYA gives an additional 20% discount on the already-discounted ₹220 offer price.
One item: ₹220 less 20% = ₹176.
The total and discount are shown before the customer continues.

ORDER FLOW:
When the customer taps Confirm Order on WhatsApp, the site prepares an order ID and opens WhatsApp with all order details addressed to +91 97736 08505.
The customer MUST tap SEND in WhatsApp. Only after they send the message will it reach the seller.
A static GitHub Pages website cannot verify that the WhatsApp message was actually sent, so the on-site message says the order request is prepared successfully, not that it has already been received.
